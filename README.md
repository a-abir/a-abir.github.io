# AbrianAbir.github.io

This repository contains the source code and static assets for my personal engineering portfolio, hosted live at [abrianabir.github.io](https://abrianabir.github.io). The site highlights my professional work, research projects, and scientific software development in advanced manufacturing, solid-state additive manufacturing, and process telemetry.

## Overview

I am an Applications Engineer for Advanced Manufacturing at Oak Ridge National Laboratory (ORNL). My graduate background is in Mechanical Engineering (M.S.) with a minor in Computer Science (B.S.) from the University of Tennessee, Knoxville.

This portfolio showcases technical write-ups and documentation across several areas:

* **Process Telemetry \& Monitoring:** In-situ monitoring and anomaly detection for Additive Friction Stir Deposition (AFSD).
* **Statistical Distance Metrics:** Applications of signed Wasserstein metrics and signal decomposition algorithms to experimental manufacturing data.
* **Simulation \& Analysis:** FEA and CFD modeling workflows using ANSYS Fluent, pyAnsys, and custom Python toolkits.

## Tech Stack \& Features

* **Frontend:** HTML5, CSS3, JavaScript (vanilla)
* **Math Rendering:** MathJax for typesetting LaTeX equations in research write-ups
* **Hosting:** GitHub Pages (automated deployment from `main` branch)
